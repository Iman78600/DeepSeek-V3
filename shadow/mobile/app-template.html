Shadow Analyst

On-device · nothing leaves your phone
Choose a file From Files, Photos, or an email attachment

Keep it on your Home Screen

  1. Tap the Share button in Safari, the square with the arrow.
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add. It opens like an app and works with no signal.

Check links from any app

Make a Shortcut so a suspicious link in Messages or Mail goes straight here.

  1. Open Shortcuts and make a new one.
  2. Turn on Use as Quick Action → Share Sheet, accepting URLs.
  3. Add the action Open URLs, and set the URL to this page followed by ?u= and the Shortcut Input.

Now share any link to it and the verdict opens straight away.

What this is, and what it is not

It is Shadow's analyst: the same detection code as the desktop browser, compiled to run on your phone. Every check happens on this device. No link and no file you check is ever uploaded anywhere.

It is not the Shadow browser. Apple requires every iPhone browser to use its own engine, so the firewall, the Tor routing and the download sandbox cannot be delivered as an app store browser. This is the analyst half, which is the half that fits.

A clean result is not a promise. It means nothing matched the patterns attackers actually use. That covers a great deal, but it cannot catch something built specifically for you.
